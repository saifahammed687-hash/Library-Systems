Run the full version

This page is a static preview. For real data, search and multi-user use, run the Flask app in the repository.

Clone the repository

Get the code from GitHub.

git clone https://github.com/saifahammed687-hash/Library-Systems.git cd Library-Systems

Install Flask

The only dependency is Flask itself.

pip install flask

Start the server

A SQLite file is created automatically on first run.

python server.py

Open it in your browser

Visit http://127.0.0.1:5000 — this time, everything you add is saved for real.
