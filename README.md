# 📚 Library Management System

একটি সাধারণ কিন্তু সম্পূর্ণ লাইব্রেরি ম্যানেজমেন্ট সিস্টেম — Python (Flask) ব্যাকএন্ড ও HTML/CSS/JS ফ্রন্টএন্ড দিয়ে তৈরি। ডাটাবেজ হিসেবে SQLite ব্যবহার করা হয়েছে, তাই আলাদা কোনো ডাটাবেজ সার্ভার সেটআপ করার দরকার নেই।

## ফিচারসমূহ

- 📖 **বই ব্যবস্থাপনা** — বই যোগ, সম্পাদনা, ডিলিট এবং খোঁজার সুবিধা
- 👥 **সদস্য ব্যবস্থাপনা** — সদস্য যোগ ও ডিলিট
- 🔄 **ইস্যু / রিটার্ন** — বই ইস্যু করা, ফেরত নেওয়া, মেয়াদোত্তীর্ণ ট্র্যাকিং
- 📊 **ড্যাশবোর্ড** — মোট বই, উপলব্ধ বই, সদস্য সংখ্যা, চলমান ও মেয়াদোত্তীর্ণ ইস্যুর পরিসংখ্যান

## ফোল্ডার স্ট্রাকচার

```
library-management/
├── server.py        # Flask ব্যাকএন্ড (API + ডাটাবেজ লজিক)
├── index.html        # ফ্রন্টএন্ড পেজ
├── styles.css         # স্টাইলশিট
├── app.js             # ফ্রন্টএন্ড লজিক (fetch API কল)
├── run.bat            # Windows-এ চালানোর জন্য
├── run.command        # macOS/Linux-এ চালানোর জন্য
└── README.md
```

চালানোর সময় প্রজেক্ট ফোল্ডারেই স্বয়ংক্রিয়ভাবে `library.db` নামে একটি SQLite ফাইল তৈরি হবে।

## চালানোর নিয়ম

### প্রয়োজনীয়তা
- Python 3.8 বা তার উপরে
- pip

### পদ্ধতি ১ — সরাসরি (যেকোনো OS)
```bash
pip install flask
python server.py
```
তারপর ব্রাউজারে যান: **http://127.0.0.1:5000**

### পদ্ধতি ২ — স্ক্রিপ্ট দিয়ে
- **Windows:** `run.bat` ফাইলে ডাবল-ক্লিক করুন
- **macOS/Linux:** টার্মিনালে `./run.command` চালান (প্রথমবার `chmod +x run.command` লাগতে পারে)

## API এন্ডপয়েন্ট (সংক্ষেপে)

| মেথড | পাথ | কাজ |
|---|---|---|
| GET | `/api/books` | সব বই দেখুন (?q= দিয়ে সার্চ) |
| POST | `/api/books` | নতুন বই যোগ করুন |
| PUT | `/api/books/<id>` | বই সম্পাদনা করুন |
| DELETE | `/api/books/<id>` | বই ডিলিট করুন |
| GET | `/api/members` | সব সদস্য দেখুন |
| POST | `/api/members` | নতুন সদস্য যোগ করুন |
| DELETE | `/api/members/<id>` | সদস্য ডিলিট করুন |
| GET | `/api/loans` | সব ইস্যু/রিটার্ন রেকর্ড দেখুন |
| POST | `/api/loans/issue` | বই ইস্যু করুন |
| POST | `/api/loans/<id>/return` | বই ফেরত নিন |
| GET | `/api/stats` | ড্যাশবোর্ড পরিসংখ্যান |

## নোট

- একটি বই ইস্যুর মেয়াদ ডিফল্টভাবে **১৪ দিন** (`server.py`-তে `LOAN_DAYS` পরিবর্তন করে বদলানো যাবে)।
- যে বই বা সদস্যের কাছে চলমান ইস্যু আছে, তাদের ডিলিট করা যাবে না — আগে বই ফেরত নিতে হবে।
